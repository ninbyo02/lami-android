# BRAVIA テレビ操作

対象実機は SONY KJ-55A9F。テレビが公開する ScalarWebAPI / IRCC を家庭内LANから使用します。
赤外線受信・学習や追加の外付け機器は必要ありません。

## 初回登録

1. テレビとラミィを動かすスマートフォンを同じホームネットワークに接続します。
2. テレビの「設定 → ネットワークとインターネット → モバイル機器設定 → リモートコントロール機能」を有効にします。
3. ラミィの「設定 → テレビ操作」で「テレビを探す」を押し、登録するテレビを選びます。IPアドレスの手入力もできます。
4. 「テレビを登録」を押し、テレビに表示された4桁の番号を入力します。
5. 電源オンも使用する場合は、テレビの「リモートスタート」を有効にします。この設定では待機電力が増えます。

PINは保存しません。認証Cookieは接続先にひも付け、バックアップ無効のアプリ専用領域に保存します。
テレビのIPアドレスを変更した場合は再登録します。「登録を解除」はラミィ内の情報を削除します。
テレビ側の登録解除はテレビの「モバイル機器の登録解除」で行います。

## チャットからの依頼

| 依頼例 | 操作 |
| --- | --- |
| テレビをつけて / テレビを消して | 電源オン / オフ |
| テレビの音量を10にして | 絶対音量指定。実機が返す音量範囲を確認 |
| テレビの音量を上げて / 下げて | リモコンの音量キーを1回送信 |
| テレビをミュートして / テレビのミュートを解除して | 消音 / 解除 |
| テレビをHDMI 1にして | テレビが公開する入力URIで切り替え |
| テレビを1チャンネルにして | 現在の放送種別で、リモコンの1番を送信 |
| テレビのチャンネルを上げて / 下げて | 次 / 前のチャンネル |
| テレビのホームに戻って / テレビの戻るを押して | ホーム / 戻る |
| テレビの上を押して / 下を押して / 左を押して / 右を押して | 方向キー |
| テレビの決定を押して | 決定 |
| テレビを再生して / 一時停止して / 停止して | 再生操作 |
| テレビの状態を教えて | 電源・音量・消音を照会 |

「ラミィ、」や末尾の「ください」に対応します。
チャンネル指定は放送局名ではなく、リモコンの1〜12番です。対応するキーがテレビにない場合はエラーを返します。
アプリの直接起動、録画予約、複合操作は今回の対象に含めていません。

## 呼び出しと結果

明示的な「テレビ…」の単独命令を、送信時に操作ツールへ直接振り分けます。
LLMや推論モデルが未設定でも、テレビ操作の送信ボタンは利用できます。
引用、否定、質問、改行を含む複合命令、画像付きメッセージからは操作を実行しません。
操作要求と実際の結果は通常の会話履歴に保存します。通常の会話の推論経路は変更しません。
音声入力を自動送信する既存の経路も、同じチャット送信口を通る構成です。音声による実機確認は別途必要です。

HTTP成功は操作の受付を表すため、返答は「操作を送りました」とします。
状態取得に成功した場合だけ、現在の状態を報告します。
電源オン時にHTTP接続できず、登録済みMACがある場合はWake-on-LANを送信します。
Wake-on-LANの送信だけで電源オンを確認したとは扱いません。
通信失敗時はリモコン操作・音量変更を自動再送しません。

接続先は家庭内LANのIPv4アドレスに限定し、HTTPリダイレクトを追いません。
取得するデバイス記述の外部エンティティを無効にし、応答サイズと通信時間を制限します。

## PCでの初回接続確認

接続確認用の tools/bravia/bravia_pair.py は、requests が導入済みのPCで実行します。
begin はテレビにPIN表示を要求します。finish はPINを標準入力または端末から受け取り、probe は状態と対応キーを読み取ります。
PINをコマンドライン引数、ログ、リポジトリに保存しません。
認証情報はユーザーの .config/lami/bravia 以下に、ディレクトリ0700・ファイル0600で保存します。
export-android は同じ初回登録をラミィへローカルで引き継ぐためのアプリ設定XMLを生成します。
このXMLは秘密情報を含むため、Gitや共有ファイルへ追加しません。
Androidへの導入・設定反映は、実機テストの一時停止指示が解除された後に行います。

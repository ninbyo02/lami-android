# デバッグ音声経路への収集接続
2026-10-15。

LamiNeuralChatVoiceEngineに任意のtraceFactoryを追加。既定nullで無効。通常のfactoryは変更せず、現在の端末や音声経路では自動収集を有効化しない。
診断呼び出し元が要求ID・テキストからLamiSpeechTraceCaptureを作成できる。生成開始、PCM準備、再生開始、再生終了、生成/再生の失敗・キャンセルに接続した。

LamiSpeechTraceGuardが記録の生成・操作・保存のExceptionを捕捉して収集を無効化する。発話処理のCancellationExceptionをcatchする箇所は従来どおり再throwし、停止制御を維持する。
記録失敗時の作業途中のファイルは合格記録と扱わない。ErrorやプロセスSIGABRTを捕捉するものではない。

ホストテスト:
記録先生成失敗、保存先をファイルで塞いだ保存失敗、完了後の二重終了保護。既存回帰を含めJVM20件・Python7件。
Android Kotlinコンパイルは別途結果JSONを参照。

残る制約:
- UI・設定・診断サービスから有効化する入口は未実装。
- モデル/実ロードランタイムの由来確認・保存容量上限は呼び出し元側で未実装。
- 先読み完了後にキューで破棄された要求は、prepare/play境界だけでは終端を記録できず未完了のディレクトリが残ることがある。
- PCM保存は有効化時のみ同期I/O。診断実行の時間を通常発話性能として扱わない。
- 新しい実機トレースはまだ採取していない。
